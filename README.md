A Java-based Employee Management System offering two interfaces in one project: a JavaFX desktop application for visual interaction and a Spring Boot REST API for programmatic backend access.
Organize employees into groups, manage their data, and persist everything to a database through Hibernate ORM - all from either a GUI or HTTP endpoints, depending on workflow.


Features

JavaFX desktop app for visual employee and group management
Spring Boot REST API for backend/programmatic access
Create, update, and delete employees and groups
Hibernate-powered database persistence
